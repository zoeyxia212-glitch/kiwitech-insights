# KiwiTech Insights

KiwiTech Insights is a New Zealand technology job-market analysis platform for junior software developers. It helps users understand which skills employers request, how demand differs by location and seniority, and what they should learn next.

## Product purpose

Junior candidates often see long lists of technologies without knowing which skills are foundational or how frequently they appear in real roles. This project turns manually collected job-listing data into practical market evidence.

KiwiTech Insights complements KiwiHire Coach:

- **KiwiTech Insights:** decide what to learn and which roles to target.
- **KiwiHire Coach:** prepare for and manage real applications.

## MVP

1. Import job listings from CSV without paid APIs.
2. Validate and store listings in a relational database.
3. Extract and aggregate skills such as Java, Spring Boot, React, .NET, Python and Power BI.
4. Compare demand by location and seniority.
5. Expose analysis through Spring Boot REST APIs.
6. Display rankings and filters in a React dashboard.
7. Export clean data for Power BI.
8. Cover core logic with automated tests and GitHub Actions.

## Planned technology stack

- Java 17
- Spring Boot
- Spring Data JPA
- PostgreSQL, with H2 for tests
- React and TypeScript
- Power BI
- JUnit, Mockito and integration testing
- GitHub Actions
- Docker and Docker Compose
