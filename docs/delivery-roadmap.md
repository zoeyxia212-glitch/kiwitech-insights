# Delivery Roadmap

## Parallel strategy

Until KiwiHire Coach reaches its first complete release:

- 80% of project time: finish and verify KiwiHire Coach.
- 20% of learning time: Java foundations needed for the next KiwiTech task.

After KiwiHire Coach is complete:

- 50%: systematic Java learning.
- 50%: KiwiTech Insights implementation.

## Phase 1 — Foundation

- Confirm CSV fields and sample dataset.
- Create Spring Boot and React applications.
- Model `JobListing` and `Skill`.
- Set up GitHub Actions.

## Phase 2 — Import pipeline

- Upload and parse CSV.
- Validate required fields.
- Report accepted and rejected rows.
- Persist valid listings.
- Add unit and integration tests.

## Phase 3 — Market analytics

- Count skill demand.
- Group by location and seniority.
- Identify common skill combinations.
- Add sorting, filtering and pagination APIs.

## Phase 4 — User experience

- Build the React dashboard.
- Add filters, empty states and validation feedback.
- Add a transparent skill-gap comparison.
- Add accessible tables and charts.

## Phase 5 — Portfolio delivery

- Export analysis data for Power BI.
- Add Docker Compose.
- Complete README and architecture documentation.
- Record a product demonstration.
- Prepare project-based interview answers.
