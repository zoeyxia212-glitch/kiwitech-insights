# Java Learning Map

Java study will run in parallel with this project. Each topic must produce working code, a test and a short verbal explanation.

| Java topic | Project application | Evidence of understanding |
|---|---|---|
| Classes and constructors | `JobListing`, `Skill`, `ImportResult` | Model valid objects and explain responsibilities |
| Encapsulation | Domain fields and validation methods | Protect valid object state |
| Interfaces | Skill extraction and import strategies | Swap implementations without changing consumers |
| Collections | Listing storage and skill aggregation | Choose `List`, `Set` and `Map` for clear reasons |
| Generics | Reusable import and result types | Explain compile-time type safety |
| Exceptions | Invalid files and malformed rows | Return useful errors without hiding failures |
| File operations | CSV import | Read resources safely and close them correctly |
| Lambda and Stream | Filtering, grouping and ranking | Compare readable stream and loop solutions |
| `equals` and `hashCode` | Skill deduplication | Explain correct `Set` and `Map` behaviour |
| Sorting and searching | Skill rankings and listing search | Explain complexity and trade-offs |
| Unit testing | Parser and analytics services | Isolate logic with JUnit and Mockito |
| Integration testing | Import-to-database and API flows | Verify multiple layers together |

## Learning rule

For every important topic:

1. Watch the relevant Java lesson.
2. Close the video and recreate a small example.
3. Apply the concept to KiwiTech Insights.
4. Write or update a test.
5. Explain the choice in English, including an alternative and trade-off.
